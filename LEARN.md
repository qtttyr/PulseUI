# LEARN.md

I built **PulseUI** as a clean, native **SwiftUI component library** — simple, polished, and actually pleasant to use.

## How I built it

1. First, I defined the visual direction: minimal, soft, premium, and modern.
2. Then I set up the project structure so every component could stay reusable and easy to maintain.
3. After that, I built the SwiftUI components one by one and tested them directly in previews.
4. I refined the details — spacing, radii, shadows, states, and animations — until everything felt right.
5. Finally, I added the web layer with Astro, CSS, and TypeScript to showcase the library properly.

## What matters

- fully native SwiftUI
- reusable real-world components
- clean UX and strong visual consistency
- free and open for everyone

## The goal

PulseUI is not just a set of UI pieces — it’s a component library built with taste, clarity, and real usability in mind.

In short:  
**I built something I’d genuinely want to use myself.**
