> **Pulse is not a bag of views.** It is a small visual language for SwiftUI:
> semantic tokens, restrained glass, purposeful motion, and components that
> remain yours after they enter your project.

## The short version

PulseUI gives you the part most component libraries leave unfinished:

- native SwiftUI APIs instead of web-shaped wrappers;
- a theme that can re-skin the entire system from one token set;
- accessibility, Dynamic Type and Reduce Motion considered at the API level;
- functional Liquid Glass for navigation, tools, menus and transient surfaces;
- a CLI that turns setup into two copy-and-run commands;
- a live Studio to design the palette before writing the first screen.

The goal is simple: **make the first screen feel designed, not assembled.**

## From zero to a themed screen

Install the CLI once:

```bash
curl -fsSL https://raw.githubusercontent.com/qtttyr/PulseUI/main/scripts/install.sh | bash
```

If the installer says that `~/.local/bin` is not on your `PATH`, run this once
in the current terminal:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Inside an existing Swift package, paste the two commands generated by the
[Studio](https://pulseuimk.vercel.app/studio/):

```bash
pulse init --accent '#D9FE3E' --radius 12
pulse add button card table chart command-palette
```

`pulse init` adds the Swift package dependency and creates a theme scaffold.
`pulse add` records the components your project actually uses. No registry,
configuration maze or handwritten boilerplate is required.

For a regular Xcode App project with no `Package.swift`, run the same commands
from the folder containing the `.xcodeproj`. PulseUI will create and attach a
`PulseUIComponents/` source group to the app target, generate the theme, and
write an `AGENTS.md` guide containing the component map and safe editing rules:

```bash
pulse init --accent '#B51A00' --radius 10
pulse add button card table
```

In this vendored Xcode mode the components are part of the app target, so use
their types directly without `import PulseUI`.

For the entire catalog:

```bash
pulse add --all
```

If you later leave PulseUI, remove only its project integration:

```bash
pulse remove --yes
```

This removes the PulseUI dependency and CLI-generated theme scaffold. It never
deletes vendored component files or your application source, so the components
remain yours and can be used, edited or downloaded again independently.

## The design model

PulseUI follows three rules:

**Content first.**  
Cards, rows, tables and charts are allowed to be clear and quiet. Glass is not
a texture sprayed over every surface.

**Motion with a reason.**  
Transitions establish hierarchy, loading communicates progress, and feedback
has a readable resting state. Every motion path respects Reduce Motion.

**Tokens over overrides.**  
Change accent, radius, typography, spacing or elevation once. Components
inherit the decision instead of collecting one-off modifiers.

```swift
import SwiftUI
import PulseUI

@main
struct DemoApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
                .pulseTheme(pulse)
        }
    }
}
```

## What is inside

### Foundations

Buttons, cards, badges, chips, labels, inputs, search, sliders, toggles,
pickers, progress, skeletons, ratings, counters, dividers and typography.

### Data and workflow

`PulseTable`, `PulseChart`, `PulseCalendar`, `PulseTimeline`, `PulseKanban`,
`PulseForm` and `PulseContentState` for real application surfaces, including
loading, empty and error states where they matter.

### Navigation and command surfaces

`PulseCommandPalette`, `PulseSegmentedControl`, `PulseNavigationBar`,
`PulseSidebar`, `PulseTabBar`, `PulseModal`, `PulseSheet` and `PulseTooltip`.

### Showcase

The Xcode playground is a live catalog, not a screenshot wall:

```bash
open Showcase/PulsePlayground.xcodeproj
```

Choose the `PulsePlayground` scheme and an iOS 26 simulator. The Studio on the
website mirrors the same idea for the browser: tune the system, select the
components, copy the commands.

## Package integration

For a direct Swift Package dependency:

```swift
dependencies: [
    .package(url: "https://github.com/qtttyr/PulseUI.git", from: "1.0.0")
]
```

Then add the product to your target:

```swift
.product(name: "PulseUI", package: "PulseUI")
```

The package currently targets Swift 6 and Apple platform version 26 or newer.

## CLI reference

```text
pulse init                         Set up dependency and theme scaffold
pulse init --accent HEX --radius N Generate Studio-matched theme tokens
pulse add button card table       Add only the components you need
pulse add --all                    Add the complete catalog
pulse add --source button         Vendor editable source into the project
pulse remove --yes                 Remove integration, preserve component files
pulse uninstall                    Remove the installed CLI (Homebrew-aware)
pulse list                         Browse the catalog
pulse doctor                       Check Swift and project setup
```

## Status

PulseUI is actively being shaped for production use. The API is intentionally
small and native, while the catalog continues to grow around real application
needs rather than novelty demos.

If you are evaluating the library, start with the [Studio](https://pulseuimk.vercel.app/studio/),
then copy the generated commands into a throwaway Swift package.
